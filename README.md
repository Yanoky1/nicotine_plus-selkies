# How install?
you need git clone `[https://github.com/Yanoky1/soulseek-selkies](https://github.com/Yanoky1/nicotine_plus-selkies)` and run 
```
docker compose build --no-cache
docker compose up -d
```
I built this Dockerfile using Claude & ChatGPT & Gemini because I wasn’t satisfied with the existing nicotine+ implementations in Docker with a web UI. It dynamically adapts the interface to the window size. To launch it, open https://ipserver:youport, click “Close,” then wait for the program to open, and add the root path to the music.
